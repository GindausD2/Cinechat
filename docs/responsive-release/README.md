# Responsive and adaptive screenshots — 26 October 2026

These 24 unedited Chromium screenshots were captured from the compiled application during the expanded responsive suite and individually opened for visual review. They show actual local fixtures, not mockups or production users. The two-viewer counts come from independent authenticated browser contexts. Long `A` chat text is an intentional wrapping stress test. Invitation links belong to deleted local fixture rooms and do not provide hosted access.

The main matrix phone views use 320×844 CSS pixels; desktop views use 1440×900; the tablet uses 768×1024. Added inline-chat/folded views use 390×844, the constrained-height composer uses 390×400, the unfolded view uses 1280×800, and dual-screen simulation uses 1114×720 with two 540px panes separated by a 34px display feature. The deletion dialog has 200% CSS text. Screenshots show the viewport; content and tall dialogs continue through normal contained scrolling. Automated geometry/focus tests also cover content below the captured area. Native mobile keyboards/notches and physical hardware were not photographed or tested.
